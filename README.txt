Learning Dynamic Grasping — project webpage

Project page: https://yilinliu77.github.io/grasping/
Paper: https://arxiv.org/abs/2610.14848

Open index.html in a modern browser. The galleries, video controls, and citation download work locally without a server or internet connection. Paper links require internet access. Keep assets/, styles.css, script.js, and citation.bib beside index.html when copying or hosting the folder.

The Citation section supports copying and downloading BibTeX. If clipboard access is unavailable, the page selects the citation for manual copying. Keep its BibTeX text and citation.bib in sync when updating the paper metadata.
